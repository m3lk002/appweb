A navegação entre as páginas foi implementada utilizando o React Router, com `BrowserRouter`, `Routes`, `Route` e `NavLink`, permitindo trocar de página sem recarregar o site. A validação do formulário foi feita por meio de uma função chamada `validar()`, que verifica se os campos foram preenchidos corretamente. Também foram adicionadas mensagens de erro para cada campo inválido, incluindo a seleção obrigatória do curso de interesse. Quando todos os dados estão corretos, uma mensagem personalizada confirma o cadastro.
